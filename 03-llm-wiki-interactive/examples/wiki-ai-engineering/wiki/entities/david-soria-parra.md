# David Soria Parra

> Co-creator of MCP at Anthropic; the AI Engineer 2026 talk behind the wiki's connectivity-stack framing, and the source of its most-quoted lines.

## Definition

Both sources that name him are downstream of the same talk. The four-layer post
quotes him directly for the connectivity thesis
[[wiki/sources/the-future-of-mcp-why-the-future-of-agents-is-mcp-skills]], and the
architecture breakdown is an explicit write-up of the same talk, attributing the
2024-demos / 2025-coding-agents / 2026-connectivity progression to him
[[wiki/sources/system-architecture-of-future-ai-apps-ui-tui-ide-extension]].

## Key claims

- "Connectivity is not one thing. The best agents use all of it - skills, CLI, MCP - together." [[wiki/sources/the-future-of-mcp-why-the-future-of-agents-is-mcp-skills]]
- Coding agents were the easy case — local, verifiable, sandboxed, a 2D UI is enough; knowledge-worker agents need five SaaS apps and a shared drive. [[wiki/sources/system-architecture-of-future-ai-apps-ui-tui-ide-extension]]
- On context bloat: "the protocol is not the problem, the client is" — progressive discovery is a harness responsibility. [[wiki/sources/system-architecture-of-future-ai-apps-ui-tui-ide-extension]]
- He is openly critical of one-to-one REST-to-MCP conversion, and says FastMCP is better than the official Python SDK he wrote. [[wiki/sources/system-architecture-of-future-ai-apps-ui-tui-ide-extension]]
