# Tivadar Danka Knowledge Graph Questions

I made it as simple as possible. The graph is stored in a JSON file, with nodes such as this:

```
{
"id": "1170279a",
"label": "anchor box",
"to": [
"980144e6",
"4c66ef54",
"be0fcf52",
"c7a48c50"
],
"from": [
"2525474d",
"b1d2905e",
"abb9f93b"
],
"category": "Computer vision",
"definition": "Pre-defined bounding boxes of various scales and aspect ratios placed at each spatial position in an object detection feature map, serving as reference boxes that the detector refines: the network predicts offsets relative to anchors rather than absolute box coordinates.",
"long_description": "**Anchor boxes** provide reference boxes for detection. Network predicts offsets $(\\Delta x, \\Delta y, \\Delta w, \\Delta h)$ relative to anchors. Matched to ground truth by IoU. Anchor-free methods (FCOS, CenterNet) avoid them."
},
```

The graph is generated by adding ~810 machine learning algorithms (gpt, u-net, etc.), and recursively generating a definition/long description, from which Claude generated new nodes with the concepts it found.

The entities are clustered by the category.

I did not do any normalization.

Graph is rendered by Three.js.
